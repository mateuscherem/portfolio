PORTFÓLIO — MATEUS CHEREM
=========================

ESTRUTURA (não mude nada de lugar)

  index.html
  cases.html
  sobre.html
  mentorias.html
  404.html
  .nojekyll            <- arquivo vazio, mas necessário
  assets/
      styles.css
      app.js
      books.js
      shots/           <- 15 imagens .webp

Os arquivos .html procuram o CSS em "assets/styles.css".
Se a pasta assets não estiver ao lado deles, o site abre sem
nenhum estilo — foi o que aconteceu antes.


COMO SUBIR NO GITHUB

1. Descompacte este ZIP.
2. No repositório: Add file -> Upload files.
3. Arraste TODOS os itens de dentro da pasta descompactada:
   os 5 arquivos .html E a pasta assets inteira.
   Arraste a PASTA assets (não os arquivos de dentro dela).
4. Commit.

O arquivo .nojekyll é oculto no Mac. Para vê-lo no Finder,
aperte Cmd + Shift + . (ponto). Se preferir, ignore o arquivo
e crie ele direto no GitHub: Add file -> Create new file,
digite  .nojekyll  no nome, salve vazio.


COMO CONFERIR SE DEU CERTO

No repositório, a raiz precisa mostrar:
   assets/   index.html   cases.html   sobre.html   mentorias.html   404.html

Se aparecer uma pasta a mais envolvendo tudo, o site vai dar 404.
Se aparecer styles.css solto na raiz, o site abre sem estilo.
